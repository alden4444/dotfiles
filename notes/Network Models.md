Describe the role of clients and servers on the Internet [2]
- Files saved on servers
- Clients send requests to the web servers
- Web servers process the requests
- and return the results to the client
- The client displays the results to the user

Thin-client
- Relies on a permanent connection to a server to function
- Can be hardware or software
- Depends on the processing power of another computer or server
- Cannot function without being connected to a networked computer or server
- Examples:
    - Cloud-based apps
    - Remote desktop software
    - Supermarket POS systems connected to a central server for prices, stock, and payments

Thick-client
- Works independently without needing constant connection to a server
- Uses the processing power of its own device to run applications
- Can function offline
- Examples:
    - Installed software
    - Standalone games
    - School or office PCs
    - Laptops

Questions:
Explain the differences between a thin client and a thick client [4]
- Thin-client depends on a permanent connection to a networked computer or server; thick-client doesn't
- Thin-client relies on the processing of the connected, networked computer; thick-client uses its own processing power
- Thin-client cannot work offline; thick-client can
- An example of thin-client is a cloud-based application like Google Docs; an example of thick-client is an application that runs on a standalone PC such as Adobe Photoshop
