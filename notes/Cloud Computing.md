- Software, services or files are hosted entirely on remote servers
- Accessed through the internet
- Examples:
    - Cloud storage:
        - Long-term storage of data that resides in a remote location
        - Accessible only via the Internet (WAN)
        - Usually on HDDs but increasingly on SSDs
        - Advantages:
            - High accessibility - anywhere with an internet connection
            - Collaboration
            - Scalability
            - Reliability
            - Security
            - No need for expensive hardware
            - No need to hire specialist IT staff
            - More efficient than millions of local servers
        - Disadvantages:
            - Needs a reliable internet connection
            - Can be expensive
            - Ongoing costs
            - Security risks
            - Less control
    - Cloud software:
        - Hosted and managed remotely
        - Accessed online
        - Provider handles:
            - Maintenance
            - Upgrades
            - Security
        - Advantages:
            - High accessibility
            - No installation needed
            - Automatic updates
            - Maintenance handled by provider
            - Scalable
            - Security included
            - Works across multiple devices
        - Disadvantages:
            - Needs internet access
            - Performance depends on internet speed
            - Ongoing costs
            - Data privacy concerns
            - Less control
            - Legal responsible
            - Features may be limited

Public Cloud
- Servers owned and managed by a third-party provider
- Services are shared with other organisations or users
- Cheaper - shared infrastructure reduces cost
- Less control over data
- Relies on provider's security measures

Private Cloud
- Servers owned and managed by the company itself
- Access is restricted to that company or organisation
- More expensive - company pays for hardware, maintenance, and staff
- More control - company manages its own data and security
- Can apply custom security policies and have full oversight
