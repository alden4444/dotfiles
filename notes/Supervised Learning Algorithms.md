Machine Learning through providing an algorithm with labeled data to predict labels for unseen examples

Two types:
- Classification:
    - Goal is to predict a categorical label, like spam or not spam
- Regression:
    - Goal is to predict a continuous value, like the value of a house given size and location

Core concepts:
- Training Data
- Features:
    - Properties of the data that serve as input, e.g. location of a house
- Labels:
    - Known outcomes associated with each data point in the training set. Represent 'correct answers'
- Training
- Prediction
- Inference:
    - Using trained model to derive insights, estimate parameters and understand relationships between variables
- Evaluation:
    - Assessing a model's performance
- Generalisation:
    - Ability of a model to predict outcomes for new data
- Overfitting:
    - Tendency of a model to learn the training data too well and memorise it
- Underfitting:
    - When model is too simple to capture underlying patterns in data
- Cross-Validation:
    - Technique used to assess how well a model will generalise to an independent dataset
- Regularisation:
    - Prevents overfitting by adding a penalty term to the loss function, which discourages the model from learning overly complex patterns
