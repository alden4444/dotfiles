- Network is two or more interconnected devices designed to
    - Share resources
    - Exchange data
    - Communicate with each other
- Enables data and resource sharing, communication, and collaboration

    Advantages
    - Devices can be shared, reducing costs
    - Software licences for networks are cheaper than for individual computers
    - Users can share files easily
    - Access to reliable, central data
    - Files can be backed up centrally
    - Enables communication

    Disadvantages
    - Expensive setup
    - Difficult to maintain
    - If the server fails, the whole network can be affected
    - Malware can affect the entire network

LANs
- Local area network
- Small geographical area (under 1 mile)
- Hardware owned by company using it
    
    Advantages
    - Allows centralised management of updates
    - Can secure devices with use of firewalls
    - Users on the network can share resources
    - Collaboration
    
    Disadvantages
    - If hardware fails, network may not function
    - Networks are more prone to attacks than standalone computers
    - Access to data can be slow depending on network traffic
    - They require maintenance to ensure software is up to date, etc.

WLANs
- Devices connected wirelessly
- Wireless access points (WAPs) or hotspots are connected to the network to enable WiFi connectivity
    
    Advantages
    - Easier to connect new devices as no cabling is required
    - Can be used both indoors and outdoors
    - Additional WAPs can be added easily extending network coverage
    - Devices on the network are more mobile as they aren't restricted by wires
    - Less cable management

    Disadvantages
    - Limited coverage
    - Bandwidth speeds can become an issue in high-traffic areas
    - Interference from other devices
    - Vulnerable to security threats due to wireless signals being intercepted

WANs
- Large geographical area (over 1 mile)
- Collection of LANs joined together
- Computers connected via routers
- Hardware ownership spread out / split up
- Fibre optic and satellite used to connect LANs together
